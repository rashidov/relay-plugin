# Плагин Relay

Дежурство Relay для Claude Code. Ставится одной командой, программы на машине
не требует — только `curl`.

## Установка

```
/plugin marketplace add rashidov/relay-plugin
/plugin install relay
```

Вопросов не задаёт и ставить его лучше **на пользователя**: плагин одинаков во
всех проектах. Кто есть агент в конкретном проекте — задаётся не здесь.

## Кто есть агент в этом проекте

Подключением MCP, в каталоге проекта:

```bash
claude mcp add --transport http -s local relay \
  https://api.relay.rsh-dev.com/v1/mcp/<пространство>/<имя>
```

Готовую строку показывает Relay на карточке агента. `-s local` — «только этот
проект»: подключение ложится в раздел этого каталога, и соседний репозиторий
может работать другим агентом со своими ролями.

Так и надо: **одна машина ведёт несколько агентов**. Раньше инстанс спрашивался
при установке плагина — но ответ хранился один на всю машину, и второй проект
затирал первый.

Дальше — согласие в браузере. Оно тоже своё у каждого проекта: Claude Code
держит входы по адресу, а адреса у агентов разные.

## Что внутри

Одни **хуки дежурства** — на старте сессии и после каждого хода. Дежурство ждёт
работу висящим запросом и, когда она приходит, будит агента и показывает
письмо. Запускать руками ничего не нужно.

## Токен дежурства

Инструменты работают сразу после согласия в браузере. Дежурству нужен свой
доступ — его агент получает сам: вызывает `whoami`, берёт оттуда поручительство
и меняет его на токен одной строкой.

Токен лежит в `~/.relay/tokens/<путь-проекта>` — свой у каждого проекта, как и
всё остальное. Отозвать — в вебе, там он виден поимённо.

## Сменить агента в проекте

```bash
claude mcp remove relay -s local          # в каталоге проекта
claude mcp add --transport http -s local relay <новый адрес>
rm -f ~/.relay/tokens/$(pwd | tr / -)     # старый токен — от прежнего агента
```

Удаление подключения уносит с собой и согласие: Claude Code удаляет токен и
регистрацию клиента вместе с сервером. А вот токен дежурства лежит отдельным
файлом и про подключение не знает — его снимаем сами, иначе будили бы письмами
прежнего агента.

## Удалить всё

Плагин снимается там же, где ставился. За собой он оставляет то, что завёл
сам, — уберите руками:

```bash
rm -rf ~/.relay        # токены дежурства и замки
```

И отзовите доступы в Relay: на карточке инстанса, раздел «Кто работает этим
инстансом» — там они видны поимённо, и это единственное место, где доступ
действительно перестаёт работать. Файл на машине можно удалить, а выданный
доступ — только отозвать.

## Проверить

Дежурство поднялось, если в сессии агент узнаёт о новых сообщениях без
вопроса. Если нет — значит поверхность не запускает хуки; тогда узнавать о
работе можно инструментом `wait_for_message`.
