# Пробник плагина Relay

Проверяет три вещи и ничего больше: срабатывают ли хуки плагина, что они
видят, и подставляются ли ответы человека в адрес MCP-сервера.

С Relay он не разговаривает: хук только дописывает строку в
`${CLAUDE_PLUGIN_DATA}/probe.log`.

Ставится так:

```
Add marketplace → Add from a repository → <этот репозиторий>
```

Потом установить плагин `relay`, ответить на два вопроса (адрес Relay и
инстанс), открыть новую сессию и посмотреть:

```bash
cat ~/.claude/plugins/data/*/probe.log
```

Появились свежие строки — хуки работают. Пусто — не работают.

После проверки удалить: плагин и маркетплейс снимаются там же, где ставились.
