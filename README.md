# Плагин Relay

Дежурство и инструменты Relay для Claude Code. Ставится одной командой,
программы на машине не требует — только `curl`.

## Установка

```
/plugin marketplace add rashidov/relay-plugin
/plugin install relay
```

Спросит две вещи: адрес Relay и идентификатор инстанса — их показывает Relay
на карточке агента.

Ставить лучше **на репозиторий** («только в этом репозитории»): инстанс — это
агент в конкретном проекте, и подключение, поставленное на пользователя,
работало бы во всех проектах сразу.

## Что внутри

- **инструменты Relay** — подключение MCP собирается из ваших ответов;
- **дежурство** — хуки на старте сессии и после каждого хода.

Дежурство ждёт работу висящим запросом и, когда она приходит, будит агента и
показывает письмо. Запускать руками ничего не нужно.

## Токен дежурства

Инструменты работают сразу после согласия в браузере. Дежурству нужен свой
доступ — его агент получает сам: вызывает `whoami`, берёт оттуда поручительство
и меняет его на токен одной строкой.

Токен лежит в `~/.relay/token`. Отозвать — в вебе, там он виден поимённо.

## Проверить

Дежурство поднялось, если в сессии агент узнаёт о новых сообщениях без
вопроса. Если нет — значит поверхность не запускает хуки; тогда узнавать о
работе можно инструментом `wait_for_message`.
